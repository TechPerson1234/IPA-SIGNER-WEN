About Nexus Signer

Nexus Signer is a free iOS sideloading companion designed to make installing IPA apps and managing signing certificates as easy as possible.

Features

  • Supports Windows, Linux (x86_64 & ARM), and macOS
  • Place RPPairing and Lockdown Pairing files into apps like StikDebug or Protokolle
  • Get intelligent fixes/suggestions for common errors
  • Install any IPA application
  • See and manage development certificates and App IDs
  • Batch IPA signing & queue management
  • Built-in IPA inspector and metadata viewer
  • Advanced certificate dashboard with expiration tracking
  • Free to use without restrictions
  • View and export detailed logs
  • Connect to devices wirelessly or via USB

And more!

How Nexus Signer works

How Nexus Signer works

Nexus Signer works by essentially pretending to be a Mac running Xcode, allowing it to use Apple's official APIs and tools for sideloading, which are intended for developers to test their apps.

  1. First, Nexus Signer acquires information about a fake Mac from an anisette server. This is why a Mac shows up in your Apple ID devices when you use Nexus Signer. If Nexus Signer hasn't logged in from this computer before, it provisions with the anisette server to get a new fake Mac identity, called an adi.pb, which can be reused for future logins. This is why you have to log in with 2FA the first time you use Nexus Signer, but not subsequent times.
  2. Next, Nexus Signer uses this information to log in to your Apple ID using Apple's GrandSlam authentication protocol. This is a multi-step process that uses the Secure Remote Password (SRP) protocol to securely transmit your password and 2FA code to Apple.
  3. Once logged in, Nexus Signer acquires a token for Xcode, which it can then use to create a developer session.
  4. When sideloading an app, Nexus Signer has to register an app ID and app group, assign the app ID to the group, and create a provisioning profile for the app. It does all of this using Apple's APIs, just like Xcode would.
  5. Nexus Signer also has to acquire a development certificate to sign the app with. If Nexus Signer doesn't have one stored, it has to create a new one and send a certificate signing request (CSR) to Apple and have it signed.
  6. Nexus Signer then uses the provisioning profile and certificate to sign the app with apple-codesign, at which point it can be transferred to the device and installed using idevice.

Beyond standard sideloading, Nexus Signer includes additional developer-oriented tools such as batch processing queues, an IPA metadata inspector, and an enhanced certificate management dashboard with visual expiration tracking — all designed to streamline the workflow for power users.
